# Ratatui Simple Template

A simple example of a Ratatui application.

This is identical to the [simple](../simple) template but using `crossterm-keybind` to handle key events.

In this templare, your users can easier to customize a keybindings, and also you will be easy to chnage key bind in the future.
These are common issue when more users using your application, 
so it will be nice to solve it ahead to prevent a lot of trival work on changing keybinds.
